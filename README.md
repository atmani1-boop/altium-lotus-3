# altium-lotus-3

## Description

This is an Altium Designer project repository for the Lotus-3 design.

## How to Open the Project / Comment ouvrir le projet

### Prerequisites / Prérequis

- [Altium Designer](https://www.altium.com/altium-designer) installed on your system
- Git installed for version control

### Opening the Project / Ouverture du projet

1. **Clone the repository / Cloner le dépôt:**
   ```bash
   git clone <repository-url>
   ```
   Replace `<repository-url>` with the URL of this repository.

2. **Open in Altium Designer / Ouvrir dans Altium Designer:**
   - Launch Altium Designer
   - Go to `File > Open Project`
   - Navigate to the cloned repository folder
   - Select the `.PrjPcb` project file to open the complete project
   - If no `.PrjPcb` file exists, you can open individual `.SchDoc` (schematic) or `.PcbDoc` (PCB layout) files directly

3. **Alternative method / Méthode alternative:**
   - Double-click the `.PrjPcb` file in Windows Explorer to open it directly in Altium Designer

## Project Structure / Structure du projet

The project may contain the following file types:
- `.PrjPcb` - Altium project file
- `.SchDoc` - Schematic documents
- `.PcbDoc` - PCB layout documents
- `.PcbLib` - PCB footprint libraries
- `.SchLib` - Schematic symbol libraries
