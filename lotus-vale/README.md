# 🪷 Lotus Vale

A relaxing 3D open world you can share with a friend: trees, flowers, butterflies, fireflies, birds, a fox, a horse, a lotus lake, a day/night cycle, ambient nature sounds and calm original music. Build a little house together.

## Play

1. Open `index.html` in Chrome, Edge or Firefox. Double-clicking the file works, and so does hosting it anywhere (GitHub Pages, Netlify Drop…).
2. **You:** type your name → **New world** → **Create & open world**. An **invite code** (like `KX4PZ`) appears at the top left.
3. **Your friend:** opens the same `index.html` → **Join a friend** → types the code.

Your world is saved in your browser. Open it again from **Your saved worlds** and it keeps the same code, so your friend can join again. The world lives in the host's browser (like a Minecraft LAN world), so friends can only join while the host has it open.

## Controls

| | |
|---|---|
| Move | WASD / ZQSD / arrows, Shift to run, Space to jump or swim |
| Camera | drag with the mouse, wheel to zoom |
| Build | **B**, pick a piece with 1–0, click to place, R to rotate, right-click or X to remove |
| Emotes | 1 wave · 2 dance · 3 sit · 4 thumbs-up · 5 yes · 6 no · 7 nap |
| Other | Enter to chat, M for music, ✨ for graphics, H for help |

- Graphics: 4× MSAA + SMAA anti-aliasing, soft bloom glow, ACES filmic colors and toon shading. Press ✨ to turn them off on slower computers.
- All sounds and music are synthesized live in the browser (Web Audio). They are original, not from any game.
